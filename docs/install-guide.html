PTCGL 導入手引書

ゲーム「Pokémon Trading Card Game Live（ポケモンカードゲーム ライブ）」を、日本から接続して、日本語の表示で遊べるようにするための、設定の手順書です。作業は大きく2つに分かれます。第1部では「ゲームを遊ぶときだけ、通信を海外のサーバー経由にする」設定を行い、第2部では「ゲームの表示を日本語にする」ファイルを追加します。番号の順番どおりに進めてください。

始める前に用意するもの

もの説明
Windows のパソコンゲーム「Pokémon Trading Card Game Live」がインストールされ、遊べる状態になっていること。
Proton のアカウント第1部の作業1で作ります。無料の範囲で使います。
日本語化のファイル一式第2部で使います。渡されたファイルを手元に用意してください。
パソコンの管理者権限途中の作業で、Windows の設定を変える場面があります。そのときに「管理者として実行」が選べる状態であること。

作業時間の目安は、第1部が約40分、第2部が約15分です。

第1部　通信の設定（ゲームのときだけ海外経由にする）

このゲームは、日本からの接続では遊べません。そこで、ゲームを遊んでいる間だけ、パソコンの通信が海外のサーバーを経由するようにします。あわせて、ゲームを始めたら自動で切り替わり、ゲームを終えたら自動で元に戻る仕組みも入れます。

作業1　Proton のアカウントを作る

  1. ブラウザで「proton.me」を開きます。
  2. 画面の「無料で始める」などの案内から登録を始め、メールアドレスとパスワードを決めて入力します。
  3. 入力したメールアドレス宛に確認のメールが届いたら、メールを開いて手続きを最後まで進めます。

決めたパスワードは、忘れないように自分の管理方法で控えてください。このあと何度かログインします。

作業2　ゲーム用の設定ファイルを手に入れる

Proton から、接続のための設定ファイルをダウンロードします。

  1. ブラウザで Proton にログインし、自分のアカウントの画面を開きます。
  2. 左側の一覧から「ダウンロード」の項目を開きます。
  3. 「WireGuard 設定ファイル」の欄で、プラットフォームは「Windows」、国は「シンガポール」を選びます。
  4. 無料サーバーの中から、どれか1つを選んで「作成」を押します。
  5. ダウンロードされたファイル（名前の最後が「.conf」になっているもの）を、デスクトップなど、自分が見つけやすい場所に置きます。

このファイルの扱いについて

ダウンロードしたファイルの中には、その人専用の「鍵」が書かれています。鍵が同じだと、他人が自分の接続になりすますことができます。このファイルは、他の人に渡したり、見せたりしないでください。人に環境を分けるときも、このファイル自体は絶対に含めず、受け取った人が自分のアカウントで自分のファイルを作るようにしてください。

国にシンガポールを選ぶ理由：このゲームが遊べる地域のうち、日本から近いのはシンガポールと香港です。この手引書ではシンガポールを使います。

作業3　設定ファイルの一部を書き換える

作業2のファイルは、そのまま使うと「パソコンの通信すべてが海外経由」になってしまいます。普段の使い方では困るため、「必要な通信だけ海外経由、それ以外は今までどおり」に変えます。書き換えるのは、ファイルの中の1行だけです。

  1. 作業2のファイルを右クリックし、「プログラムから開く」→「メモ帳」を選びます。
  2. 開いた中身のうち、下のほうにある「[Peer]」と書かれた部分を探し、その中にある「AllowedIPs =」で始まる行を見つけます。この行には、海外経由にする通信の範囲が、カンマで区切られた数字の並びで書かれています。
  3. まず、海外経由から「外す」範囲を2種類決めます。
    • 1つ目は、サーバー自身のあて先です。ファイルの下のほうにある「Endpoint =」の行に書かれた数字（例：「123.45.67.89:51820」のうち、コロンより前の「123.45.67.89」の部分）がそれです。この数字に「/32」を付けたもの（例：「123.45.67.89/32」）を外します。これを外さないと、接続が自分自身に向かってしまい、通信が止まります。
    • 2つ目は、自宅の中で使う機器（プリンターや、家庭内の保存用の機器など）の範囲です。例として「192.168.1.0/24」のような書き方をします。該当する機器がなければ、この2つ目は不要です。
  4. ブラウザで「CIDR Split Calculator」などの名前の計算ページを開きます。「0.0.0.0/0」という全体の範囲から、手順3で決めた範囲を引く計算をすると、残りの範囲が数字の並びで表示されます。
  5. 計算結果の数字の並びをすべてコピーし、手順2で見つけた「AllowedIPs =」の行を置き換えます。行の先頭の「AllowedIPs = 」の部分は残し、その後ろを計算結果に変えてください。
  6. メモ帳で上書き保存します。
  7. 最後に、ファイルの名前を半角英数字で「ptcgl-vpn.conf」に変えます。このあとの作業では、この名前で統一して進めます。

作業4　WireGuard アプリを入れて、設定ファイルを読み込む

WireGuard は、海外経由の接続を行うためのアプリです。WireGuard の中では、接続の設定のことを「トンネル」と呼びます。

  1. ブラウザで「wireguard.com」のインストールのページを開き、Windows 版をダウンロードして、インストールします。
  2. WireGuard を起動します。
  3. 画面にある「ファイルからトンネルをインポート」というボタンを押し、作業3で作った「ptcgl-vpn.conf」を選びます。
  4. 一覧に「ptcgl-vpn」と表示されれば、読み込みは完了です。

この時点では、「有効化」のボタンは押さないでください。接続を入れたり切ったりするのは、次の作業で入れる「見張り役」のプログラムが行います。読み込んだときに、暗号化された控えのファイルが自動で作られます。見張り役はその控えを使います。

作業5　見張り役のプログラムを置く

見張り役は、ゲームが始まったか・終わったかを2秒ごとに確認し、始まっていれば接続を入れ、終わってから30秒たったら接続を切る、小さなプログラムです。Windows に最初から入っている「PowerShell」という仕組みで動きます。

  1. エクスプローラー（フォルダの画面）を開き、C ドライブの直下に「PTCGL-VPN」という名前の新しいフォルダを作ります。
  2. メモ帳を開き、次のプログラムをすべてコピーして貼り付けます。
# wg_autolink.ps1
$ErrorActionPreference = 'Continue'
$procName  = 'Pokemon TCG Live'
$svcName   = 'WireGuardTunnel$ptcgl-vpn'
$wgExe     = 'C:\Program Files\WireGuard\wireguard.exe'
$dpapiPath = 'C:\Program Files\WireGuard\Data\Configurations\ptcgl-vpn.conf.dpapi'
$modeFile  = 'C:\PTCGL-VPN\wg_mode.txt'
$reqFile   = 'C:\PTCGL-VPN\vpn_request.txt'
$log       = 'C:\PTCGL-VPN\wg_autolink.log'
function Write-Log($msg) {
  $line = "$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') $msg"
  Add-Content -Path $log -Value $line -Encoding UTF8
}
function Start-Tunnel {
  $svc = Get-Service -Name $svcName -ErrorAction SilentlyContinue
  if (-not $svc) {
    & $wgExe /installtunnelservice $dpapiPath | Out-Null
    Start-Sleep -Seconds 2
    $svc = Get-Service -Name $svcName -ErrorAction SilentlyContinue
  }
  if ($svc -and $svc.Status -ne 'Running') {
    Start-Service -Name $svcName -ErrorAction SilentlyContinue
    Start-Sleep -Seconds 2
  }
  return (Get-Service -Name $svcName -ErrorAction SilentlyContinue)
}
function Stop-Tunnel {
  $svc = Get-Service -Name $svcName -ErrorAction SilentlyContinue
  if ($svc -and $svc.Status -eq 'Running') {
    Stop-Service -Name $svcName -Force -ErrorAction SilentlyContinue
    Start-Sleep -Seconds 2
  }
  return (Get-Service -Name $svcName -ErrorAction SilentlyContinue)
}
$created = $false
$mutex = New-Object System.Threading.Mutex($true, 'Global\PTCGL-WgAutoLink', [ref]$created)
if (-not $created) { exit 0 }
Write-Log "WATCHER_START"
$absent = 0
$lastMode = 'auto'
while ($true) {
  try {
    if (Test-Path $reqFile) {
      $req = (Get-Content $reqFile -Raw -ErrorAction SilentlyContinue)
      Remove-Item $reqFile -Force -ErrorAction SilentlyContinue
      if ($req) { $req = $req.Trim().ToLower() }
      if ($req -eq 'on') {
        $svc = Start-Tunnel
        Write-Log "MANUAL_ON (service=$($svc.Status))"
      } elseif ($req -eq 'off') {
        $svc = Stop-Tunnel
        Write-Log "MANUAL_OFF (service=$($svc.Status))"
      }
    }
    $mode = 'auto'
    if (Test-Path $modeFile) {
      $raw = (Get-Content $modeFile -Raw -ErrorAction SilentlyContinue)
      if ($raw) { $mode = $raw.Trim().ToLower() }
    }
    if ($mode -eq 'manual') {
      if ($lastMode -ne 'manual') { Write-Log 'MODE_MANUAL auto link suspended' }
      $lastMode = 'manual'
      Start-Sleep -Seconds 2
      continue
    }
    if ($lastMode -eq 'manual') { Write-Log 'MODE_AUTO auto link resumed'; $absent = 0 }
    $lastMode = 'auto'
    $game = Get-Process -Name $procName -ErrorAction SilentlyContinue
    $svc  = Get-Service -Name $svcName -ErrorAction SilentlyContinue
    if ($game) {
      $absent = 0
      if (-not $svc) {
        & $wgExe /installtunnelservice $dpapiPath | Out-Null
        Start-Sleep -Seconds 2
        $svc = Get-Service -Name $svcName -ErrorAction SilentlyContinue
        Write-Log 'GAME_DETECTED tunnel service was missing, installed from dpapi config'
      }
      if ($svc -and $svc.Status -ne 'Running') {
        Start-Service -Name $svcName -ErrorAction SilentlyContinue
        Start-Sleep -Seconds 2
        $svc = Get-Service -Name $svcName -ErrorAction SilentlyContinue
        Write-Log "GAME_DETECTED -> VPN_ON (service=$($svc.Status))"
      }
    } else {
      $absent++
      if ($absent -eq 15 -and $svc -and $svc.Status -eq 'Running') {
        Stop-Service -Name $svcName -Force -ErrorAction SilentlyContinue
        Start-Sleep -Seconds 2
        $svc = Get-Service -Name $svcName -ErrorAction SilentlyContinue
        Write-Log "GAME_ABSENT_30S -> VPN_OFF (service=$($svc.Status))"
      }
    }
  } catch { Write-Log "ERROR $($_.Exception.Message)" }
  Start-Sleep -Seconds 2
}
  1. メモ帳の「ファイル」→「名前を付けて保存」を選びます。保存する場所を「C:\PTCGL-VPN」にし、ファイル名を「wg_autolink.ps1」にします。そのとき、下のほうにある「ファイルの種類」を「すべてのファイル」に変えてから保存してください。
  2. 保存したあと、C:\PTCGL-VPN のフォルダを開き、ファイル名が「wg_autolink.ps1」になっているか確認します。もし「wg_autolink.ps1.txt」のように最後に「.txt」が付いていたら、名前を変更して「.txt」の部分を消してください。

作業6　見張り役が自動で動き続けるように登録する

パソコンにサインインしたとき、見張り役が自動で始まって動き続けるよう、Windows の「タスクスケジューラ」という仕組みに登録します。管理者権限が必要です。

  1. 画面左下のスタートボタンを押し、「PowerShell」と入力します。
  2. 表示された「Windows PowerShell」を右クリックし、「管理者として実行」を押します。「このアプリがデバイスに変更を加えることを許可しますか」と出たら「はい」を押します。黒い画面（文字だけの画面）が開きます。
  3. 次の行をコピーして貼り付け、Enter キーを押します。

schtasks /create /tn "PTCGL-WgAutoLink" /sc onlogon /ru SYSTEM /rl highest /tr "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\PTCGL-VPN\wg_autolink.ps1" /f

  1. 成功の表示が出たら、続けて次の行を貼り付けて Enter キーを押します。これで見張り役が今すぐ動き始めます。

schtasks /run /tn "PTCGL-WgAutoLink"

作業7　ゲームの通信が、海外経由でしか外に出られないようにする

見張り役が接続を入れるまでの数秒間や、接続が切れたときに、ゲームが直接つながってしまわないようにします。Windows のファイアウォール（通信を止める仕組み）に、ゲームについての決まりを作ります。管理者権限が必要です。先に、調べるものが2つあります。

調べるもの その1：ゲームのファイルの場所

  1. デスクトップにあるゲームのアイコンを右クリックし、「プロパティ」を押します。
  2. 「リンク先」の欄に書かれている文字列が、ゲームのファイルの場所です。両端の「"」は除いて、このあと使います。

調べるもの その2：回線の名前

  1. 作業6と同じ方法で、PowerShell を管理者として開きます。
  2. 次の行を入力して Enter キーを押すと、回線の一覧が表示されます。「Name」の列に書かれているのが回線の名前です（有線の場合は「イーサネット」のような名前です）。このあと使う回線の名前を控えます。

Get-NetAdapter

決まりを作る

  1. 管理者の PowerShell に、次の行を貼り付けます。貼ったあと、行の中の「<ゲームの場所>」を調べた文字列に、「<回線の名前>」を控えた名前に、それぞれ書き換えてから Enter キーを押します。

New-NetFirewallRule -DisplayName "PTCGL-Block-NonVPN" -Direction Outbound -Program "<ゲームの場所>" -Action Block -InterfaceAlias "<回線の名前>" -Profile Any

  1. エラーが出なければ完了です。使う回線が複数ある場合（有線と無線の両方など）は、「<回線の名前>」のところに、名前をカンマで区切って並べてください（例："イーサネット","Wi-Fi"）。

WireGuard の接続そのものは、この決まりの対象に含めないでください。含めてしまうと、海外経由の通信まで止まってしまいます。

作業8　動きを確認する

  1. ゲームを起動します。
  2. 数秒待ってから、ブラウザで「IPアドレス 確認」と検索して確認ページを開き、国が「シンガポール」と表示されるか確認します。
  3. ゲームにログインし、対戦などができるか確認します。
  4. ゲームを終了します。1分ほど待ってから、もう一度ブラウザで IPアドレスを確認し、国が「日本」に戻っているか確認します。
  5. 「C:\PTCGL-VPN」フォルダにある「wg_autolink.log」をメモ帳で開き、「VPN_ON」と「VPN_OFF」の行があるか確認します。

5つすべてを確認できれば、第1部は完了です。

作業9（任意）　手動で入れる・切るためのボタンを置く

自動の切り替えではなく、自分のタイミングで接続を入れたい・切りたい人向けの作業です。デスクトップにボタンを置き、押すだけで切り替えられるようにします。

まず、ボタンの裏側で動く小さなプログラムを3つと、画面を出さずに実行するためのファイルを1つ作ります。作り方は作業5と同じで、メモ帳に貼って、C:\PTCGL-VPN に保存します。

1つ目：ファイル名「vpn_on.ps1」（手動にして、今すぐ入れる）

Set-Content -Path 'C:\PTCGL-VPN\wg_mode.txt' -Value 'manual' -Encoding ASCII
Set-Content -Path 'C:\PTCGL-VPN\vpn_request.txt' -Value 'on' -Encoding ASCII

2つ目：ファイル名「vpn_off.ps1」（手動にして、今すぐ切る）

Set-Content -Path 'C:\PTCGL-VPN\wg_mode.txt' -Value 'manual' -Encoding ASCII
Set-Content -Path 'C:\PTCGL-VPN\vpn_request.txt' -Value 'off' -Encoding ASCII

3つ目：ファイル名「vpn_auto.ps1」（自動に戻す）

Set-Content -Path 'C:\PTCGL-VPN\wg_mode.txt' -Value 'auto' -Encoding ASCII
Remove-Item 'C:\PTCGL-VPN\vpn_request.txt' -Force -ErrorAction SilentlyContinue

4つ目：ファイル名「run_hidden.vbs」（画面を出さずに実行するためのファイル）

Dim sh
Set sh = CreateObject("WScript.Shell")
sh.Run "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File " & Chr(34) & WScript.Arguments(0) & Chr(34), 0, False

次に、デスクトップへボタンを作ります。

  1. デスクトップの何もないところを右クリックし、「新規作成」→「ショートカット」を選びます。
  2. 「項目の場所を入力してください」の欄に、次をそのまま貼り付けます。

wscript.exe //B //Nologo "C:\PTCGL-VPN\run_hidden.vbs" "C:\PTCGL-VPN\vpn_on.ps1"

  1. 「次へ」を押し、名前に「PTCGL VPN 入れる」と付けて「完了」を押します。
  2. 同じ手順で、「vpn_off.ps1」の場所を指定した「PTCGL VPN 切る」と、「vpn_auto.ps1」の場所を指定した「PTCGL VPN 自動に戻す」も作ります。

使い方：「入れる」か「切る」を押すと手動の状態になり、そのあとは、ゲームを閉じても接続は自動では切れなくなります。自動に戻すときは「自動に戻す」を押してください。対戦の途中で「切る」を押すと、ゲームの接続も切れます。

第2部　日本語表示の追加

ゲームの中の文章を日本語の文章に置き換え、カードの絵を日本語版のものに差し替える仕組みを追加します。第1部が終わっていなくても進められますが、ゲームで確認する場面では第1部の設定が必要です。

作業1　土台のプログラム（BepInEx）を入れる

BepInEx は、ゲームに外付けの仕組みを読み込ませるための土台です。これをゲームのフォルダに入れることで、第2部の仕組みが動くようになります。

  1. ブラウザで「BepInEx」の配布ページ（GitHub の BepInEx のページにある「Releases」という配布の一覧）を開きます。
  2. バージョン「5.4.23.6」の中から、Windows の64ビット版のファイルをダウンロードします。ファイル名は「BepInEx_win_x64_5.4.23.6.zip」のような形です。
  3. ダウンロードしたファイルを右クリックし、「すべて展開」を選んで解凍します。
  4. ゲームのインストールフォルダを開きます。開き方：デスクトップのゲームのアイコンを右クリックし、「ファイルの場所を開く」を押すと、ゲームの実行ファイルのあるフォルダが開きます。
  5. 解凍した中身をすべて、ゲームのフォルダにコピーします。
  6. コピーしたあと、ゲームの実行ファイルと同じ場所に、「BepInEx」という名前のフォルダと、「winhttp.dll」という名前のファイルが並んでいるか確認します。この形になっていれば正しく置けています。

作業2　日本語表示のファイルを置く

  1. 渡された日本語化のファイル一式を、手元に用意します。
  2. 一式の中に「install.bat」という名前のファイルがある場合は、そのファイルをダブルクリックしてください。中身が自動で決まった場所にコピーされ、この作業は終わりです。作業3に進んでください。
  3. 「install.bat」がない場合は、手で置きます。ゲームのフォルダの中にある「BepInEx」フォルダを開き、その中の「plugins」フォルダを開きます。渡されたファイル（日本語化のプログラム本体、文字の表示を整えるファイル、日本語の文章のデータ、カードの対応データ）を、すべてこの「plugins」フォルダにコピーします。どのファイルを置くかは、渡された一式の中にある説明のファイルに書かれているとおりにしてください。

作業3　起動して確認する

  1. ゲームを起動します。初めての起動では、読み込みに少し時間がかかります。
  2. コレクションの画面を開き、画面の文章が日本語で表示されているか確認します。
  3. 対戦の画面で、カードの絵が日本語版のものになっているか確認します。
  4. うまく表示されない場合は、ゲームのフォルダの「BepInEx」フォルダにある「LogOutput.log」というファイルをメモ帳で開き、日本語化のプログラムの名前が書かれた行があるか確認します。行がなければ、作業1と作業2で、ファイルの置き場所がずれている可能性があります。

文章とカードの絵が日本語で表示されれば、導入は完了です。
